# Data directory

Download the data from the [Kaggle Event Recommendation Engine Challenge](https://www.kaggle.com/competitions/event-recommendation-engine-challenge/data) using an authorized Kaggle account.

Extract the following files into `data/raw/` before running the project:

```text
data/raw/train.csv
data/raw/users.csv
data/raw/events.csv
data/raw/event_attendees.csv
data/raw/user_friends.csv
```

The raw competition data are not included in this repository. The source code reads them locally and does not modify them.
